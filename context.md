# Project context

## Objective

Portfolio/practice redesign of the Fastway Couriers South Africa homepage (reference: https://www.fastway.co.za/). Not affiliated with Fastway; no real APIs, no data collection.

## Intended users

SMEs, existing courier customers, parcel trackers, eCommerce businesses, prospective franchisees, people looking for a local depot.

## Current milestone

All five milestones complete. Waiting for the owner's completion signal before any LinkedIn/interview deliverables (do **not** create them until the owner says `DONE — GO TO LINKEDIN`).

## Architecture

- Next.js 16.4 App Router, TypeScript strict, Tailwind v4 via the `@tailwindcss/turbopack` loader (`next.config.ts`).
- `cacheComponents` is enabled (scaffold default): no `Date.now()` / `new Date()` / `Math.random()` in server components.
- Server Components by default. Client components: `Navbar`, `HeroCard`, `DepotFinder`, `Reveal`, `MotionProvider`.
- All repeated content lives in `data/*.ts`; components only render it.
- The page prerenders as static (`○ /`).

## Important files

- `app/globals.css`: design tokens (`@theme`), focus and reduced-motion base styles, `container-page` utility.
- `app/layout.tsx`: metadata ("… — Practice Redesign", `robots: noindex`), viewport, Geist via `next/font`, `MotionProvider`.
- `data/depots.ts`: depot data plus `filterProvinces()` (unit-tested in `tests/depots.test.ts`).
- `data/footer.ts`: footer columns (derived from navigation/depot data), social links, `copyrightYear`, disclaimer text.
- `AGENTS.md`: generated by Next.js and re-created by `next dev`, so it is committed.

## Key decisions

- Visual style follows the reference site: navy `#0b2f8a` / `navy-deep` `#061d5c` for the header, hero wash, franchise panel and footer; crimson `#c8102e` for CTAs (white text ≈ 5.8:1); white/light-grey content sections. A dark theme was tried and dropped at the owner's request.
- Hero photo is a Pexels stock image of an unbranded truck (`public/images/hero-truck.jpg`, Pexels licence, credited in README), not Fastway's photo; the logo is text only. Never copy Fastway imagery or logos.
- `brand-bright` currently equals `brand` (kept as the token for red text). `subtle` `#626d84` is ≥ 4.5:1 on canvas, surface and elevated.
- Focus outlines use `--focus-ring`: navy by default and white inside `.on-dark` (header, hero text, hero tabs, franchise panel, footer); `.on-light` resets it for white panels nested in navy areas.
- `<body suppressHydrationWarning>`: browser extensions add attributes to `<body>` before hydration.
- Desktop nav from `xl` (1280px). Below that, the hamburger menu, because five groups plus CTAs wrap at 1024px.
- `framer-motion` package; `MotionConfig reducedMotion="user"` plus a CSS reduced-motion fallback.
- Lucide v1 has no brand icons, so social icons are the former lucide outlines inlined (`components/SocialIcon.tsx`).
- Tests use `node:test` with native TS stripping (no test framework dependency). `tsconfig` sets `allowImportingTsExtensions` for that.

## Known limitations

- Placeholder `#` links; no sub-pages; depot data is city names only.
- Turbopack's persistent dev cache (`.next/dev`) once served stale CSS after a `@theme` edit. If token changes don't show in `next dev`, stop it and delete `.next/dev`.
- Moderate `npm audit` advisories in dev-only ESLint deps (minimatch). Production deps: 0.
