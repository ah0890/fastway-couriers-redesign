# Project context

## Objective
Portfolio/practice redesign of the Fastway Couriers South Africa homepage (reference: https://www.fastway.co.za/). Not affiliated with Fastway; no real APIs, no data collection.

## Intended users
SMEs, existing courier customers, parcel trackers, eCommerce businesses, prospective franchisees, people looking for a local depot.

## Current milestone
Milestone 5 — Verification and documentation (next). Milestones 1–4 done.

## Architecture
- Next.js 16.4 App Router, TypeScript strict, Tailwind v4 via `@tailwindcss/turbopack` loader (configured in `next.config.ts`).
- `cacheComponents` is enabled (scaffold default): avoid `Date.now()` / `new Date()` / `Math.random()` in server components.
- Server Components by default; `"use client"` only for interactive parts.

## Important files
- `app/globals.css` — design tokens (`@theme`), base styles, `container-page` utility.
- `app/layout.tsx` — metadata (title "… — Practice Redesign", `robots: noindex`), viewport, Geist font via `next/font` (self-hosted at build).
- `AGENTS.md` — generated by Next.js; re-created by `next dev`, so it is committed.

## Key decisions
- Brand red `#d6001c` (white text contrast ≈ 5.3:1). Change colours only in `app/globals.css`.
- `framer-motion` package (not `motion`) to match the requested library name.
- Lucide v1 ships no brand icons, so social icons are small inline SVGs.

## Commands
`npm run dev` · `npm run lint` · `npm run typecheck` · `npm run build`

## Git
Branch `main`, remote `origin` (github.com/ah0890/fastway-couriers-redesign). Commits use the existing configured identity; pushing each milestone was authorised by the owner.
